# Marketing Performance Intelligence Dashboard

Production-oriented Next.js dashboard template for analyzing Meta Ads + Shopify ROI.

## Features
- Upload-only flow (CSV/XLSX)
- Server-side API proxy stubs for Meta and Shopify
- Combined spend/revenue ROI model (Meta ROAS, True ROAS, Attribution Gap)
- Attribution confidence tiers and attribution quality indicator
- Presentation-ready charts and report page
- Downloadable Meta/Shopify CSV templates

## Run
```bash
npm install
npm run dev
```
